# CapKit Commercial Path

CapKit is the focused authorization primitive inside the broader ABSuite ecosystem.

## Open-source role

CapKit should be easy to adopt, inspect and integrate. Its job is distribution: become the smallest useful security primitive for agents that need narrowly scoped authority.

## Commercial opportunities

CapKit can lead into:

- ABSuite deployment and integration
- enterprise policy integration
- managed authorization infrastructure
- security architecture engagements
- agent governance audits
- support and maintenance
- commercial connector/policy packs

## Adoption funnel

```
npm install
   ↓
first capability issued
   ↓
production integration
   ↓
ABSuite evidence / verification
   ↓
enterprise deployment
```

## What to measure

- weekly downloads
- dependent projects
- active production installations
- time to first successful capability
- integrations
- GitHub issues/PRs
- organizations requesting support
- paid pilots generated through CapKit

Stars are distribution, not revenue.

## Product rule

Keep the primitive small and trustworthy. Do not turn CapKit into a giant framework merely to create more features. The strongest commercial path is a small authorization primitive that naturally connects to a larger evidence and governance system.
